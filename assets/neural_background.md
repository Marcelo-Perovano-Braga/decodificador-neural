# Neural background artwork

- Project asset: `assets/neural_background.png`.
- Created for this application's fullscreen/background update using the built-in
  image-generation tool through the imagegen skill; no CLI/API-key fallback.
- Decorative illustration of connected biological neurons. It is not a
  representation of the simulated graph, a microscope image, or recorded data.
- The generated PNG is included unchanged. Qt fits and tints it at runtime for
  the current viewport/theme. No animation, network request or new dependency.
- PyInstaller already includes the complete assets directory, so the image is
  available to the rebuilt Windows executable.

## Generation prompt

Use case: stylized-concept. Asset type: wide desktop application background
illustration, landscape 16:9, at least 1920x1080 if possible. Primary request:
a refined biological neural network illustration for a neuroscience research
desktop application. Interconnected neuron cell bodies and delicate branching
dendrites/axons, graceful long organic filaments; layered subtle depth, soft
luminous synaptic points, tasteful scientific visualization rather than a
schematic. Dark charcoal/navy space with desaturated teal/cyan filaments, a few
restrained warm amber synaptic points, matching a dark research dashboard with
teal accents. Composition: coherent network distributed across the image,
strongest recognizable neuron silhouettes near the outer margins, quieter
negative space in upper-left and central areas for application content. The
artwork should still read at low opacity behind interface panels. High
craftsmanship, fine detail, atmospheric but restrained, dark matte background,
no harsh central spotlight, no giant objects. Decorative illustrative asset
only; no scientific labels. No text, typography, numbers, arrows, logos,
watermark, brain-shaped outline, circuit board, UI panels, or diagram boxes.
Generate only the background artwork, not an app screenshot.
